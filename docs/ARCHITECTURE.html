MicrophoneAudioProvider · microphone-audio-provider.ts

  • RMS sampled ~20 Hz → AudioLevelEvent

OpenAIRealtimeProvider · openai-realtime-provider.ts

WebRTC client · event router · self-healing
  • RTCPeerConnection · DataChannel oai-events
  • SDP offer/answer via POST /session
  • Listens for session.input_transcript.completed / output_transcript.completed + delta variants
  • Persistent renewal-retry timer survives stopped state
  • onStatus(fn) subscription API — UI re-frames internal stopped as idle
Reliability hardening · 2026-05-19 MAX_SEGMENT_DURATION_MS = 12 000 — promotes stuck partials to final.
Stale detector — audioActiveSamplesSinceDc ≥ 100 + per-mic dB floor (-40 / -48 / -52) avoids natural-pause false triggers.
Renewal backoff [30 s · 1 m · 3 m · 5 m · 10 m cap] tuned for live meetings.
ICE / PC failed → auto renewSession(); never silent stop.
Diag dump every 10 s → console.info('[openai-rt diag]', …) with sample-counter, dc-event-count, pc/ice state.

§ 04.1

Event Contracts

provider-agnostic · stable internal interface 
TranscriptEvent   { provider, mode, source, segmentId,
                    status: partial | revised | final,
                    text, startMs, endMs?, confidence?, revisionOf? }

TranslationEvent  { provider, mode, sourceSegmentId,
                    status: draft | refined | final,
                    sourceText, targetText, sourceLanguage, targetLanguage, updatedAt }

HealthEvent       { component: transport | audio | stt | mt | summary,
                    state: idle | connecting | … | degraded | failed, msg }

AudioLevelEvent   { rmsDb, source }   // ~20 Hz · drives MicLevelBar
