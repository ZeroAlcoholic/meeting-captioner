# 會議使用手冊（Meeting Playbook）

> 給「操作字幕的人」的一頁手冊：什麼會議、開什麼設定、出問題怎麼救。
> 系統架構與工程細節見 `ARCHITECTURE.md` / `PROVIDER_BACKENDS.md`。
> 最後驗證：2026-06-11（全情境瀏覽器實測通過）。

---

## 一、快速對照表：會議類型 → 設定

| 會議類型 | 情境(Scenario) | 模式(Mode) | 後端 | 音源 | Mic 設定 | 雙語 |
|---|---|---|---|---|---|---|
| **實體會議**（會議室投影字幕） | 實體會議 | Online Full | OpenAI 或 Gemini | 🎤 麥克風 | **Meeting**（預設） | ON |
| **線上會議旁聽**（Teams/Zoom/Meet） | 線上會議旁聽 | Online Full | OpenAI 或 Gemini | 🔊 系統音訊（自動） | （自動 off） | ON |
| **機密／內部敏感會議** | 實體會議 | **Hybrid Privacy**（音訊不出機器）或 **Full Offline**（完全離線） | — | 🎤 / WASAPI | Meeting | ON |
| **跨語交流／國際訪客** | 實體會議 | Online Full | **Gemini**（自動偵測 70+ 語言） | 🎤 | Meeting | ON |
| **大型簡報／演講** | 實體會議 | Online Full | 任一 | 🎤 | **Far**（講者離 mic 遠） | 視需求 |

操作節奏：選情境 → 確認後端與語言對（EN→繁中） → Start → `F` 全螢幕。

## 二、兩個線上後端怎麼選

| | **OpenAI**（預設） | **Gemini 3.5 Live Translate** |
|---|---|---|
| 字幕節奏 | 逐字即時 partial | **連續串流**（落後講者數秒），逐句歸檔 |
| 繁體中文 | 模型出簡體 → 系統自動 OpenCC 轉繁 | **原生繁中**（台灣用語） |
| 多語混講 | 自動偵測來源語 | 自動偵測 70+ 語，**講者已說目標語時會靜音不翻**（原文照出） |
| 成本顯示 | ✅ 有計費面板 | ❌ 尚無（注意用量） |
| 長會議 | 25 分自動續期（無感） | 自動壓縮+續接+GoAway 重連 |

建議：一般會議用 OpenAI（成本可視）；重視繁中道地度或多語場合用 Gemini。

## 三、會議中出問題怎麼救（不丟字幕記錄）

**核心原則：永遠先 Pause，不要 Stop+重開。**

| 狀況 | 動作 |
|---|---|
| **後端故障／一直 reconnecting** | **⏸ Pause → Settings 切另一個後端 → ▶ Resume**。記錄完整保留，由另一後端在同一份字幕上接續（已實測）。 |
| 中場休息 | ⏸ Pause（停止擷取與計費）→ ▶ Resume |
| 系統音訊斷了（對方看到「Stop sharing」） | 畫面顯示 audio failed → Pause → Resume 重新選「整個螢幕＋分享系統音訊」 |
| 講者換人後辨識變差 | 確認 Mic 設定 = **Meeting**（多人共用 mic 專用，預設） |
| 想暫時凍結畫面講解 | 按 **空白鍵**（僅凍結顯示，擷取繼續）；再按恢復 |
| 會後留存 | Stop → **⬇ Export**（記錄在 Stop 後仍保留） |

注意：**直接按 Start（非 Resume）會開新場次並清空畫面記錄**；要接續一律走 Pause/Resume。

## 四、快捷鍵與小知識

- `F` 全螢幕字幕板　`空白鍵` 凍結/恢復顯示　`.` 顯示隱藏按鈕
- 滾輪在任何位置都能捲歷史；往上捲會暫停自動置底，右下出現「↓ N new」點擊回到最新
- 雙語開關（顯示原文）：Settings → Source transcript；OpenAI 關掉可省 whisper 費用
- 🔊 線上會議旁聽：分享時務必選 **「整個螢幕」並勾選「分享系統音訊」**（選單一視窗通常抓不到聲音）
- 設定（語言對/後端/音源/Mic）會記住；字幕記錄重新整理也會還原

## 五、隱私分級速查

| 等級 | 模式 | 出機器的資料 |
|---|---|---|
| 一般 | Online Full | 音訊 → OpenAI 或 Google |
| 敏感 | Hybrid Privacy | 僅**辨識後文字** → 雲端翻譯（音訊不出去） |
| 機密 | Full Offline | **完全不出機器**（本地 Whisper + 本地翻譯） |
